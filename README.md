## Como executar

### Com Docker (recomendado)

```bash
docker compose up --build
```

A API ficará disponível em `http://localhost:5000`.

### Localmente, sem Docker

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
python -m app.app
```
